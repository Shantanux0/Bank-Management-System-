# 💳 Bank Management System & ATM Simulator (Java)

A **console-based Java mini project** that simulates basic banking and ATM functionalities. This project was built to strengthen Java fundamentals like OOP, file handling, and exception handling.

---

## 🚀 Features

- 🏦 Account creation (with auto-generated account numbers)
- 💰 Deposit and withdraw money
- 📄 Mini statement generation
- 🔐 Secure login with PIN
- 🔄 Change PIN functionality
- ❌ Exit/Logout functionality

---

## 🛠️ Tech Stack

- **Language**: Java
- **Concepts Used**:
  - Object-Oriented Programming (OOP)
  - File Handling
  - Exception Handling
  - Conditional Statements & Loops
  - Console-based user input

---

## 🎯 Learning Goals

- Reinforce **Java fundamentals** with a hands-on project
- Understand real-world banking logic
- Practice **modular programming** and clean code structure
